# Emon Downloader — Multi-page Neon Edition

## Included pages
- `index.html` — Home and quick link checker
- `youtube.html` — YouTube links
- `facebook.html` — Facebook links
- `tiktok.html` — TikTok links
- `history.html` — local browser history
- `about.html` — project details and limitations
- `style.css` — responsive modern neon UI; colors cycle every 2 seconds
- `app.js` — link validation, opening, local history, direct MP4/WebM download attempt

## Android + GitHub Pages setup
1. Download and extract this ZIP on your Android phone.
2. Create a Public repository at https://github.com/new (e.g. `emon-downloader`).
3. Upload all files from this folder into the repository root. Do not upload only the ZIP.
4. Open Settings → Pages.
5. Select Deploy from a branch, branch `main`, folder `/(root)`, then Save.
6. Open the URL GitHub Pages provides.

## Important
This is a static website. It opens validated YouTube/Facebook/TikTok links and does not extract/download every platform's video. GitHub Pages does not provide a backend. Use official save/download options or permitted direct video file URLs. Downloading direct URLs may fail due to CORS/server restrictions.
